# Contributing to youtube-search-python

Thank you for your interest in contributing to youtube-search-python.

special thanks to https://github.com/BillaSpace/yt-search-python

This project aims to provide a lightweight Python library for searching YouTube without requiring the YouTube Data API.

## How to contribute

You can help by:

* Reporting bugs
* Suggesting features
* Improving documentation
* Adding tests
* Fixing compatibility issues
* Improving reliability when YouTube changes its structure

## Before submitting changes

Please make sure:

* Your code is clean and readable
* Existing functionality is not broken
* Relevant tests are added or updated
* Documentation is updated if needed

## Pull requests

Open a pull request with a clear description of the change, why it is needed, and how it was tested.

Small improvements are welcome.
