# Security Policy

## Reporting a Vulnerability

If you discover a security issue in youtube-search-python, please report it responsibly.

Do not create a public issue for sensitive security problems.

Instead, contact the maintainer through GitHub or email with:

* A clear description of the issue
* Steps to reproduce
* Possible impact
* Any suggested fix, if available

I will review valid reports and try to fix security issues as soon as possible.

## Supported Versions

The latest release is the supported version of this project.
